Relay

An AI receptionist for small businesses. It answers phone calls in real time, books appointments, and hands off to a person when it should.

  • OpenAI Realtime API
  • Telnyx
  • AgentOS
  • pgvector
  • Stripe
  • Turborepo

View the demo →

  • Real-time voice agent with ~300 ms response latency, using intent detection and function calling to book Google Calendar appointments during the call.
  • Warm transfer that briefs a human before connecting the caller.
  • RAG knowledge base with hybrid vector and keyword search over websites, files, Google Drive and APIs, with review, versioning and publishing.
  • Guardrail layer that checks every reply against private facts. Business hours, holidays and call routing are enforced in code, not in the prompt.
  • One inbox for phone, web chat, Gmail, Outlook, WhatsApp and SMS, with transcripts, summaries and recordings.
  • Usage-based credit billing and self-serve onboarding to a first test call in under 10 minutes.
